# /farm

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/farm [option] [setting]
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
Controls which mob to farm among other settings, lists help
<!--cmd-desc-end-->

## Options

| Option | Description |
|--------|-------------|
| `help` | Displays help text |
| `on|off` | Will turn on&#124;off farming with INI settings |
| `radius #` | Will set radius to number provided |
| `zradius #` | Will set zradius to number provided |
| `farmmob <name>` | Specify a mob to farm |
| `farmmob clear` | Will clear the FarmMob setting and attack anything not on an alertlist |
| `castdetrimental on|off` | Will turn on and off casting of single target detrimental spells |
| `debug on|off` | Will turn on and off debugging messages. |
| `MedAt [#]` | Will show you when you will med mana. It will also set to an optional number provided. |
| `MedTill [#]` | Will show you when you will stop medding. It will also set to an optional number provided. |
| `HealAt [#]` | Will show you when you will med health. It will also set to an optional number provided. |
| `HealTill [#]` | Will show you when you will stop medding health. It will also set to an optional number provided. |
| `MedEndAt [#]` | Will show you when you will med endurance. It will also set to an optional number provided. |
| `MedEndTill [#]` | Will show you when you will stop medding endurance. It will also set to an optional number provided. |
